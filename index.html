Advanced Computer Architecture

From the end of easy scaling to the machines that replaced it

Frequency scaling ended two decades ago; everything since — out-of-order execution, deep memory hierarchies, multicore, GPUs, NPUs — is a response to that. We follow that story, and we read a real RISC-V CPU written in Bluespec while we do it.

Instructors: Priyesh Shukla · Suresh Purini

01 — Overview

About the Course

A graduate course on how modern processors actually get their performance — and on why each mechanism exists, which is always because some easier source of speed ran out.

The course opens with the walls: Dennard scaling, power, memory, and ILP. It then works through instruction-level parallelism (pipelining, dynamic scheduling, speculation, VLIW), the memory hierarchy and the side channels it leaks through, cache coherence and memory consistency, and finally the accelerators that dominate today's silicon — GPUs and NPUs — closing with recent ISCA/MICRO work.

Running through the early part of the course is a second thread: we read hardware, not just diagrams. Three lectures build up Bluespec SystemVerilog and then walk two real RISC-V implementations — Drum (unpipelined) and Fife (pipelined) — from Nikhil's Learn Bluespec and RISC-V Design. Every structure the later ILP lectures describe on a whiteboard has a counterpart you can compile and run.

Designing Hardware: Bluespec & RISC-V · Suresh Purini
The one idea: Drum and Fife have identical instruction semantics and are wired up differently. Each stage is a pure function; the unpipelined machine calls them in sequence, the pipelined one calls the same functions from concurrent rules separated by FIFOs. Pipelining, scoreboarding, Tomasulo and the reorder buffer are then re-wirings of one datapath — not rewrites.

Books, Code & Lectures

Primary sources

  • Learn Bluespec and RISC-V Design
    Rishiyur S. Nikhil · the book, the BSV source for the Drum and Fife CPUs, and the exercises. The spine of lectures 3–5 and the reference for the ILP lectures that follow.
    GitHub
  • Drum & Fife — interactive code walkthrough
    Browse the two CPUs by symbol and file, with guided tours through the fetch/decode/execute path. Use it alongside L5.
    Open →
  • High Performance Computer Architecture: Part 1
    Milos Prvulovic (Georgia Tech, via Udacity) · short-video lecture series. Lessons 1 and 2 are the assigned pre-class viewing for L1 and L2; later lessons and the follow-on parts are a useful second pass on pipelining, dynamic scheduling, coherence and consistency.
    Playlist
  • ACA Virtual Labs (IIIT Hyderabad)
    Browser-based simulators for the ILP and coherence material — data hazards, scoreboarding, Tomasulo, reorder buffers, branch prediction, MSI/MESI/MOESI and directory coherence, and roofline analysis. Run them alongside the matching lecture.
    Experiments →
  • Bluespec Compiler (bsc)
    Open-source BSV compiler and Bluesim simulator — what you need to build and run every example in lectures 3–5.
    GitHub
  • Computer Architecture: A Quantitative Approach
    Hennessy & Patterson · the standard reference for the ILP, memory hierarchy and TLP modules.
