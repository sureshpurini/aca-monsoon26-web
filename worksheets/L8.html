      Reservation stations

      the tag is the new name: Qj=Mult1 watching the CDB for Mult1 Vj=R[f4] read from the register file at issue Vj=Add1 arrived on the CDB from Add1

      Register result status

      Which station will produce each register. This is the whole of Tomasulo's renaming: the register file no longer says what a register holds, only who owes it a value.

      Instruction status

      Three stages, not four. There is no Read Operands — operands are captured at issue or arrive by broadcast.

      A letter means work is happening in that cycle; a bare colour means the instruction is waiting. Turn on name the stalls to label the waiting cells too — useful on short runs, noisy on a 40-cycle divide.

      All three machines, this program

      Same instructions, same units, same latencies. Only the machine changes — which is the only way the numbers mean anything.

      Keyboard: ← → step, Space play/pause, Home / End jump, 1 2 3 switch example, Q W E switch machine.

      Issue is in program order, one instruction per cycle. Every check is evaluated against the state at the start of a cycle and all the actions for that cycle are applied together — which is why a value written in cycle n cannot be read until n+1.

      On the scoreboard and the renamed scoreboard nothing is forwarded: a consumer waits for its producer to reach the register file. Tomasulo's common data bus is precisely the removal of that rule.
