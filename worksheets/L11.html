Lecture 11 — build the schedule yourself Machine V has no interlocks. If you place an operation before its input has landed, the machine will not stall for you — it will read the old value. This worksheet refuses those placements and tells you which rule you broke.

The rules this worksheet enforces

1 — one operation per unit per cycle. A word has one FP+, one FPx, two memory units and two integer units. An operation may only issue in a slot of the right kind.

2 — a result is readable exactly L cycles after it issues. Integer 1, load 3, FP 4. A consumer placed earlier than that reads the previous value of the register. The hardware does not check, so this worksheet does.

3 — in the kernel, the producer ran on the previous trip. The kernel repeats every II cycles, so a value produced at cycle p of one trip is read at cycle c of the next: the real distance is c + II − p, and that is what must cover the latency.

Loop control (addi, bne) is placed for you, with the memory offsets already repaired, so you can concentrate on the dependence chain.
