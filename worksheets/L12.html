The hardware constants are AMD's published figures for XDNA 2 (32 compute tiles, 512 INT8 MAC/cycle each, 64 KB of data memory per tile, two 512-bit load units = 128 B/cycle). Everything else on this page is computed by the same model the slides use. Nothing here was measured — there is no NPU behind this page.
